# Stack Técnica

## Decisão inicial

- TypeScript
- React
- SQLite

## Objetivo

A solução será construída com TypeScript e React para manter um front-end moderno, eficiente e bem estruturado. O SQLite será usado como banco leve para o ambiente inicial, especialmente para gerir notícias e conteúdo administrativo da área de cadastro.

## Premissas

- Front-end responsivo e moderno.
- Compatibilidade com navegadores atuais.
- Boa experiência em dispositivos móveis.
- Estrutura simples para evolução futura.
